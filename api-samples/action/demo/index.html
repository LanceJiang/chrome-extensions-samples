Action API 演示

Before experimenting with these APIs, we recommend you pin the extension's action button to your toolbar in order to make it easier to see the changes. 在体验这些API之前，我们建议您将扩展的操作按钮固定到工具栏，以便更容易看到变化。

enable / disable 启用/禁用

点击下面的切换启用状态按钮将启用或禁用Chrome工具栏和扩展菜单中的扩展操作按钮。

禁用时，点击操作按钮不会打开弹出窗口或触发action.onClicked事件。

Popup 弹出窗口

本演示的manifest.json文件将 action.default_popup的值设置为 popups/popup.html。我们可以使用 action.setPopup 在运行时更改该行为。

注册一个处理程序来更改操作按钮的行为。更改后，点击操作按钮将打开您最喜欢的新网站。

Badge Text 徽章文本

操作按钮的徽章文本是具有纯色背景的文本覆盖层。这提供了一个被动的UI界面与用户共享信息。它最常用于显示通知计数或当前页面上采取的操作数量。

徽章文本颜色

action.setBadgeTextColor 方法允许您更改徽章文本的颜色。

action.getBadgeTextColor 方法允许您读取徽章文本的当前颜色。

图标

action.setIcon 方法允许您通过提供图像路径或原始 ImageData 来更改操作按钮的图标。

悬停文本

当鼠标悬停在扩展操作按钮上时，操作的标题可见。

可以使用 action.getTitle 和 action.setTitle 方法分别在运行时读取和更改此值。
